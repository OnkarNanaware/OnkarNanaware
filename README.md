### 🧭 About Me

- 🏗️ I design **end-to-end system architecture** — from the database schema to the deployment pipeline, not just one layer of the stack.
- 🔗 I specialize in **integration**: making frontend, backend, infra, and third-party services talk to each other cleanly.
- 🛡️ Currently building **FraudShield AI** — a real-time financial fraud detection system with behavioral anomaly detection, mule account prediction, and cross-bank threat intelligence sharing.
- ⚡ Active in **competitive hackathons**, where I own architecture decisions under time pressure and still ship a working end-to-end demo.
- 🧪 Big believer in **testing + CI/CD as part of the build**, not an afterthought.
- 🌱 Always learning, always breaking things (safely) to understand how they work.
